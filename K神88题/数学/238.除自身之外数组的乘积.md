不能使用除法
如果用暴力方法，就是一个个遍历，需要$O(N^2)$
显然不行，需要优化

题解的思路是这样的：
把每个元素的自身之外的数组乘积的乘式展开，发现是一个对角线为1的矩阵
$b[0]=1*a[1]*a[2]...*a[n-2]*a[n-1]$
$b[1]=a[0]*1*a[2]...*a[n-2]*a[n-1]$
$b[0]=a[0]*a[1]*1...*a[n-2]*a[n-1]$
$...$
$b[n-2]=1*a[1]*a[2]...*1*a[n-1]$
$b[n-1]=1*a[1]*a[2]...*a[n-2]*1$

从下三角开始，比如
$b[0]=1$
$b[1]=b[0]*a[0]$
$b[2]=b[1]*a[1]$
...
$b[n-1]=b[n-2]*a[n-2]$

然后从下往上处理上三角
$tem=1$
$tem=tem*a[n-1]$
$b[n-2]=b[n-2]*tem$
$tem=tem*a[n-2]$
$b[n-3]=b[n-3]*tem$
...
$tem=tem*a[1]$
$b[0]=b[0]*tem$

```python
class Solution:

    def productExceptSelf(self, nums: List[int]) -> List[int]:

        n=len(nums)
        b=[1]*n

        for i in range(1,n):
            b[i]=b[i-1]*nums[i-1]

        tem=1
        for i in range(n-2,-1,-1):
            tem=tem*nums[i+1]
            b[i]=b[i]*tem

        return b
```

- 时间复杂度：$O(N)$
- 空间复杂度：$O(N)$
