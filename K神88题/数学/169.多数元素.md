次数 **大于** `⌊ n/2 ⌋` 的元素，即$n//2$

当然我们可以用计数的方法，然后排序返回次数最多的
```python
class Solution:
    def majorityElement(self, nums: List[int]) -> int:
        cnt=collections.Counter(nums)
        return cnt.most_common(1)[0][0]
```

- 时间复杂度：Counter的时间复杂度是$O(N)$，取最大值的时间复杂度是$O(M)$，最坏情况$N=M$，整体上时间复杂度$O(N)$
- 空间复杂度：$O(N)$

时间复杂度应该是没办法再优化了，但是空间复杂度可以优化，因为我们只需要返回一个，而不需要总是全部维护

如果我们把不同元素看做不同的敌对势力，相同的元素是同一势力，元素数目就是该势力的士兵数目，不同势力之间单兵作战能力相同，即只会同归于尽，那不管他们之间如何打，即便是所有势力团结起来，最后剩下的也一定是众数，如果他们没有团结起来而是内耗，那只会更加凸显众数的优势
```python
class Solution:

    def majorityElement(self, nums: List[int]) -> int:

        res=0
        cnt=0

        for i in range(0,len(nums)):
            if cnt==0:
                res=nums[i]
                cnt=1

            else:
                if nums[i]==res:
                    cnt+=1
                else:
                    cnt-=1

        return res
```
空间复杂度$O(1)$
