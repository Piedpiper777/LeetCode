拆分为大于等于2个正整数的和，并使其积最大
$$\frac{(m+n)}{2}>=\sqrt[2]{mn}$$
当且仅当$m>0,n>0,m==n$时等号成立
推广到任意指数
$$\frac{a_1+a_2+...+a_k}{k}>=\sqrt[k]{a_1*a_2*a_3*...*a_k}$$
当且仅当所有数相等并且全部为正时等号成立

如果拆分数字$k$确定，则平均分时乘积最大
如果假设拆分数字为$k$，$n=kx$, $x=\frac{n}{k}$
乘积最大值$x^k$，由于$k=\frac{n}{x}$，所以$x^k=x^{\frac{n}{x}}=(x^{\frac{1}{x}})^n$
$n$已知，则问题转化为求$x^{\frac{1}{x}}$的最大值

令$y=x^{\frac{1}{x}}$
两边同时取对数：$lny=\frac{1}{x}lnx$
两边同时对$x$求导：
$\frac{dy}{dx}*\frac{1}{y}=\frac{1-lnx}{x^2}$
$\frac{dy}{dx}=\frac{1-lnx}{x^2}*x^{\frac{1}{x}}$
令$y'=0$，则：$1-lnx=0$，可得$x=e$
$y=x^{\frac{1}{x}}$先增后减，在$x=e$处取最大值，但是$e$不是整数，看其两边$x=2,3$
$y(2)=2^{\frac{1}{2}}$
$y(3)=3^{\frac{1}{3}}$
$y(2)^6=2^3=8<y(3)^6=3^2=9$
所以取最大值的整数点是$x=3$

把$n/3$，即$n=3a+b$，余数可能有三种情况：
- b=0：直接平均拆分为a份，最大乘积是$3^a$
- b=1：可以是$3^a*1$，也可以是$3^{a-1}*4=3^a+3^{a-1}$，显然后者更大
- b=2：$3^a*2$

当然以上分析是针对$n>3$的情况的，针对$n<=3$的情况，由于题目去要求必须拆分，因此拆除一个1，返回$n-1$

```python
class Solution:

    def integerBreak(self, n: int) -> int:

        if n>3:
            a=n//3
            b=n%3

            if b==0:
                return 3**a
            if b==1:
                return 3**(a-1)*4
            if b==2:
                return 3**a*2

        else:
            return n-1
```
