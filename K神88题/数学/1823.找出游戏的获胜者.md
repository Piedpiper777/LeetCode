可以构建一个链表，每次删除第k个节点，但是需要循环n-1轮，每次都要数k个数，时间复杂度$O(nk)$，时间复杂度太高了，不行

这是著名的约瑟夫环问题
对于$(n,k)$，即有n个节点，要数的数是k，k可能大于n也可能小于等于n
我们可以模拟一下：
1——2——3-----1 (n=3)
- k=1(<n=3)，毙掉1(i=0)，下次开始节点：2(i=1)
- k=6(>n=3)，毙掉3(i=2)，下次开始节点：1(i=0)
好像毙掉的节点的索引是`(k-1)%n`，下次开始的节点`k%n`

如果设`t=k%n`，则新序列是：$t,t+1,t+2,t+3...0,1,2,...t-3,t-2$  （即$(n,k)$的解是$t-1$）

变成了$(n-1,k)$
对应关系：
$(n-1,k)$           $(n,k)$删除后
0                              t
1                            t+1
...                            ...
n-2                         t-2
——————————————————
x                            (x+t)%n
子问题内部编号 x → 原大圈真实编号

`x`是$(n-1,k)$问题新排列的索引，而`(x+t)%n`是$(n,k)$问题中的原索引值，

假设我们已经算出：**小环$n-1$最终活下来的人，在小环内部编号是 $f(n-1)$，则对应到大环中的索引是$f(n) = \big(f(n-1) + t\big) \bmod n$，化简的$f(n) = \big(f(n-1) + k\big) \bmod n$

$f(n)$ 可由 $f(n−1)$ 得到，$f(n−1)$ 可由 $f(n−2)$ 得到，……，$f(2)$ 可由 $f(1)$ 得到；因此，若给定 $f(1)$ 的值，就可以递推至任意 $f(n)$ 。而$(1,k)$问题的解 $f(1)=0$ 恒成立，即无论 $k$ 为何值，长度为 $1$ 的数字环留下的是一定是数字 $0$ 。
```python
class Solution:

    def findTheWinner(self, n: int, k: int) -> int:
        x=0
        for i in range(2,n+1):
            x=(x+k)%i
        return x
```
