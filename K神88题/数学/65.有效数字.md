规则可以转换成指数之前和指数之后是否合法

- 指数之前，去掉开头的正负号之后，指数符号之前必须满足：
	- 至少有一个数字
	- 至多有一个小数点
	- 除了数字和小数点不能有其他符号
- 指数之后，去掉开头的正负号之后，指数符号之后必须满足：
	- 至少有一个数字
	- 除了数字之外不能有其他的符号

```python
class Solution:

    def isNumber(self, s: str) -> bool:

        n=len(s)

        # 先处理指数之前

        ## 正负号：
        i=0
        if s[i] in '+-':
            i+=1

        ## 小数点和数字
        has_dot = has_digit=False
        while i<n and s[i] not in 'eE':

            ### 小数点
            if s[i]=='.':
                if has_dot:
                    return False
                has_dot=True

            ### 数字
            elif '0'<=s[i]<='9':
                has_digit=True

            ### 其余字符
            else:
                return False
            i+=1

        if not has_digit:
            return False

        # 指数之后
        if i<n and s[i] in 'eE':
            i+=1
            ## 正负号
            if i<n and s[i] in '-+':
                i+=1
            ## 必须有数字
            if i==n:
                return False
            ## 必须全部是数字
            while i<n and '0'<=s[i]<='9':
                i+=1

        return i==n
```
