设一个数字$n$是个$x$位数，记第$i$位位$n_i$，则可将$n$写成$n_xn_{x-1}...n_2n_1$
记当前数位位$cur$，左边的称为高位$high$，右边的称为低位$low$，$10^i$称为位因子$digit$

看几个例子，观察一下规律：

1. $n=2304$
对于第$2$位，此位$1$出现的情况如下：
- 第$4$位为$2$，第$3$位的取值为$0-2$，第$1$位的取值为$0-9$，共$30$种
- 第4位的取值为$0-1$，第$3$位的取值为$0-9$，第$1$位的取值为$0-9$，共$200$种
- 合计$230=high*digit$种

2. $n=2314$
对于第$2$位，此位$1$出现的情况如下：
- 自身，共$1$种
- 第$4$位为$2$，第$3$位为$3$，第$1$位的取值为$0-3$，共$4$种
- 第$4$位为$2$，第$3$位的取值为$0-2$，第$1$位的取值为$0-9$，共$30$种
- 第$4$位的取值为$0-1$，第$3$位的取值为$0-9$，第$1$位的取值为$0-9$，共$200$种
- 合计$235=high*digit+low+1$种

3. $n=2324$
- 第$4$位为$2$，第$3$位为$3$，第$2$位为$1$，第$1$位的取值为$0-9$，共$10$种
-  第$4$位为$2$，第$3$位的取值为$0-2$，第$1$位的取值为$0-9$，共$30$种
- 第$4$位的取值为$0-1$，第$3$位的取值为$0-9$，第$1$位的取值为$0-9$，共$200$种
- 合计$240=(high+1)*digit$种

```python
class Solution:

    def countDigitOne(self, n: int) -> int:

        digit=1
        res=0
        
        high=n//10
        cur=n%10
        low=0
        
        while high != 0 or cur !=0:

            if cur==0:
                res+=high*digit
            elif cur==1:
                res+=high*digit+low+1
            else:
                res+=(high+1)*digit

            low+=cur*digit
            cur=high%10
            high//=10
            digit*=10

        return res
```
时间复杂度 $O(logn)$ ： 循环内的计算操作使用 $O(1)$ 时间；循环次数为数字 n 的位数，即 $log_{10}^n$，因此循环使用 $O(logn)$ 时间。
