两种思路
1.交换

比如对于1,2,3三个数字，全排列就是分别考虑三个数字在第一位的情况，然后考虑剩余两个数字在第二位的情况，最后一位无需考虑
因此，对于原始nums，我们可以先让其余数字与第一位交换，然后递归考虑第二位...
```python
class Solution:

    def permute(self, nums: List[int]) -> List[List[int]]:

        n=len(nums)

        def dfs(x):

            if x ==n-1:
                res.append(list(nums))
                return

            for i in range(x,n):
                nums[i],nums[x]=nums[x],nums[i]
                dfs(x+1)
                nums[i],nums[x]=nums[x],nums[i]

        res=[]
        dfs(0)

        return res
```


2.是否用过的思路去考虑

```python
class Solution:

    def permute(self, nums: List[int]) -> List[List[int]]:

        n=len(nums)
        res=[]
        path=[0]*n
        used=[False]*n

        def dfs(i):
        
            if i == n:
                res.append(list(path))
                return

            for j,u in enumerate(used):
                if not u:
                    path[i]=nums[j]
                    used[j]=True
                    dfs(i+1)
                    used[j]=False

        dfs(0)

        return res
```
