选还是不选的思想
默认先不选，考虑dfs(i+1)

然后考虑选，将当前元素加进去，再考虑后续递归，因为可以选择重复元素，所以i其实不用变
最后恢复现场

```python
class Solution:

    def combinationSum(self, candidates: List[int], target: int) -> List[List[int]]:

        res=[]
        path=[]

        def dfs(i,need):

            if need==0:
                res.append(list(path))
                return

            if need<0 or i==len(candidates):
                return

            dfs(i+1,need)

            path.append(candidates[i])
            dfs(i,need-candidates[i])
            path.pop()

        dfs(0,target)

        return res
```

也可以用枚举的思想
```python
class Solution:

    def combinationSum(self, candidates: List[int], target: int) -> List[List[int]]:

        res=[]
        path=[]
        candidates.sort()

        def dfs(i,need):

            if need==0:
                res.append(list(path))
                return

            for j in range(i,len(candidates)):

                if candidates[j]>need:
                    break

                path.append(candidates[j])
                dfs(j,need-candidates[j])
                path.pop()

        dfs(0,target)

        return res
```
