### 思路
与46题区别在于有重复数字，需要去重

我们先回顾一下46题的解法：
首先可以用交换的思想，其次可以用是否用过来排列
如果有重复元素，怎么处理呢

当然我们可以对46题的结果去重，不过结果是一个列表，如何去重呢？

对于交换的思路，我们可以判断想要换的元素是否已经处理过了，如果处理过了就跳过，如果没处理过，就加入字典或者集合即可

```python
class Solution:

    def permuteUnique(self, nums: List[int]) -> List[List[int]]:

        n=len(nums)
        res=[]

        def dfs(i):
        
            if i==n-1:
                res.append(list(nums))
                return

            dic=set()

            for j in range(i,n):
            
                if nums[j] in dic:
                    continue

                dic.add(nums[j])
                nums[j],nums[i]=nums[i],nums[j]
                dfs(i+1)
                nums[j],nums[i]=nums[i],nums[j]

        dfs(0)

        return res
```
