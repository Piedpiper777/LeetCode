### 思路
递归，对每个位置都要递归一下

递归条件：
如果索引超出边界或者当前点不是要找的字母，直接返回False

如果已经找够了长度，返回True

递归主体：
对上下左右四个坐标进行递归


```python
class Solution:

    def exist(self, board: List[List[str]], word: str) -> bool:

        def dfs(i,j,k):

            if not 0<=i<len(board) or not 0<=j<len(board[0]) or board[i][j]!=word[k]:
                return False

            if k==len(word)-1:
                return True

            board[i][j]=''

            for x,y in (i-1,j),(i+1,j),(i,j-1),(i,j+1):
                if dfs(x,y,k+1):
                    return True
            board[i][j]=word[k]        
            return False

  

        for i in range(len(board)):
            for j in range(len(board[0])):
                if dfs(i,j,0):
                    return True

        return False
```
