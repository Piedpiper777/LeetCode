### 思路
先序遍历，递归
按照 “根、左、右” 的顺序，遍历树的所有节点。在先序遍历中，记录从根节点到当前节点的路径。当路径满足 (1) 根节点到叶节点形成的路径 且 (2) 各节点值的和等于目标值 targetSum 时，将此路径加入结果列表。

```python
class Solution:

    def pathSum(self, root: Optional[TreeNode], targetSum: int) -> List[List[int]]:

        res=[]
        path=[]

        def dfs(node,target):

            # 递归终止条件，到叶子节点
            if not node:
                return

            # 递归主体

            # 先把根节点处理掉
            path.append(node.val)
            target-=node.val

            # 判断是否满足条件
            if target==0 and not node.left and not node.right:
                res.append(list(path))

            # 先左后右
            dfs(node.left,target)
            dfs(node.right,target)

            # 恢复现场
            path.pop()

        dfs(root,targetSum)

        return res
```
