这一题与39题的区别在于，一个数字只能选一次，然后还不能重复

只能选一次好解决，但是如果候选列表本身就有重复元素就麻烦了

用枚举的思路也许更好理解一点
```python
class Solution:

    def combinationSum2(self, candidates: List[int], target: int) -> List[List[int]]:

        res=[]
        path=[]
        n=len(candidates)
        candidates.sort()

        def dfs(i,need):

            if need==0:
                res.append(list(path))
                return
                
            for j in range(i,n):
                if candidates[j]>need:
                    break

                # 去重
                if j>i and candidates[j]==candidates[j-1]:
                    continue

                path.append(candidates[j])
                dfs(j+1,need-candidates[j])
                path.pop()

        dfs(0,target)

        return res
```

选或不选的思路
```python
class Solution:

    def combinationSum2(self, candidates: List[int], target: int) -> List[List[int]]:

        res=[]
        path=[]
        n=len(candidates)
        candidates.sort()

        def dfs(i,need):

            if need==0:
                res.append(list(path))
                return

            if i==n or need<0 or candidates[i]>need:
                return

            # 选
            path.append(candidates[i])
            dfs(i+1,need-candidates[i])
            path.pop()

            # 不选
            x=candidates[i]
            i=i+1
            while i<len(candidates) and candidates[i]==x:
                i+=1
            dfs(i,need)

        dfs(0,target)

        return res
```
