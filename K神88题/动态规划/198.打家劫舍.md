### 思路

第$i$家的收益=$max(第i-1家的收益，第i-2家的收益+第i家的财富)$
即$res[i]=max(res[i-1],res[i-2]+nums[i])$

首先还是先递归嘛，边界条件是前两个点
我们分析一下不加`@cache`的复杂度
- 时间复杂度：对于最后一个$n-1$元素，需要计算$n-2$和$n-3$元素，而$n-2$需要计算$n-3$和$n-4$，$n-3$需要计算$n-4$和$n-5$，即每个递归层需要计算2次，时间复杂度是$O(2^n)$
- 空间复杂度：看递归深度，应该是$O(n)$
如果加上了`@cache`时间复杂度就是$O(n)$

```python
class Solution:

    def rob(self, nums: List[int]) -> int:

        n=len(nums)
        @cache
        def dfs(i):
            if i==0:
                return nums[0]
            if i==1:
                return max(nums[0],nums[1])
            return max(dfs(i-1),dfs(i-2)+nums[i])
        return dfs(n-1)
```

写成递归的方式就是维护一个长度为n的列表，每个值代表这一家的res，最后返回$res[-1]$即可
```python
class Solution:

    def rob(self, nums: List[int]) -> int:

        n=len(nums)

        if n==1:
            return nums[0]

        dp=[0]*n
        dp[0]=nums[0]
        dp[1]=max(nums[0],nums[1])

        for i in range(2,n):
            dp[i]=max(dp[i-1],dp[i-2]+nums[i])

        return dp[n-1]
```
时间复杂度和空间复杂度都是$O(n)$

我们可以继续优化空间复杂度，同样地两种方法，原地修改、维护几个中间变量而不是整个列表，可以把空间复杂度优化到$O(1)$

原地修改：
```python
class Solution:

    def rob(self, nums: List[int]) -> int:

        n=len(nums)

        if n==1:
            return nums[0]

        nums[1]=max(nums[0],nums[1])

        for i in range(2,n):

            nums[i]=max(nums[i-1],nums[i-2]+nums[i])

        return nums[n-1]
```

维护中间变量：
```python
class Solution:

    def rob(self, nums: List[int]) -> int:

        n=len(nums)

        if n==1:
            return nums[0]

        prepre=nums[0]
        pre=max(nums[0],nums[1])

        cur=pre

        for i in range(2,n):
            cur=max(prepre+nums[i],pre)
            prepre,pre=pre,cur

        return cur
```

也可以写的更优雅
```python
class Solution:

    def rob(self, nums: List[int]) -> int:
        prepre, pre = 0, 0
        for num in nums:
            # 这里的 prepre 相当于 dp[i-2]，pre 相当于 dp[i-1]
            prepre, pre = pre, max(pre, prepre + num)
        return pre
```
