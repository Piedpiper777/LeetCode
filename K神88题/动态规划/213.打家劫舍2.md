与198题的区别在于，本题是一个环
我想有这样一个思路
把问题拆成两个198问题的比较
即：第一家选还是不选
选的话，就等于是nums[0] +[2,n-1]的值，不选的话就等于是[1,n]的值
直接调用rob1即可
```python
class Solution:

    def rob1(self,nums):
        @cache
        def dfs(i):
            if i<0:
                return 0
            return max(dfs(i-1),dfs(i-2)+nums[i])
        return dfs(len(nums)-1)

    def rob(self, nums: List[int]) -> int:
        n=len(nums)
        return max(nums[0] + self.rob1(nums[2:n-1]), self.rob1(nums[1:]))
```
- 时间复杂度：$O(n)$
- 空间复杂度：$O(n)$
优化空间复杂度可以修改rob1
