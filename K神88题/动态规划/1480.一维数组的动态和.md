### 思路

首先肯定可以用循环的方式一个个叠加

```python
class Solution:

    def runningSum(self, nums: List[int]) -> List[int]:

        a=nums[0]
        res=[a]
        
        for i in range(1,len(nums)):
        
            a=a+nums[i]
            res.append(a)

        return res
```

线性时间复杂度
考虑结果数组则是线性空间复杂度

如果想要继续优化空间，可以原地修改数组
```python
class Solution:

    def runningSum(self, nums: List[int]) -> List[int]:

        for i in range(1,len(nums)):
            nums[i]+=nums[i-1]

        return nums
```
