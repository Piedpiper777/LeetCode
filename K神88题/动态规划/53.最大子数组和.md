### 思路

对于以$nums[i]$结尾的连续数组，其最大子数组和$res[i]$为$max(res[i-1]+nums[i],nums[i])$

同样，先递归，边界条件是$i==0$
我们先分析一下不加`@cache`的复杂度：
- 时间复杂度：对于第`i`个元素，需要递归到1，递归i次（比如，对于$i=2$需要$dfs(2)-dfs(1)-dfs(0)$，递归了2次），由于需要循环遍历每一个元素进行递归，所以加起来就是$0+1+2+3+...+n-1$，时间复杂度是$O(n^2)$
- 空间复杂度：$O(n)$？递归的空间复杂度取决于**系统递归栈的最大深度**。

然后我们可以加上`@cache`，这样时间复杂度就是$O(n)$了，因为以每个元素结尾的最大子数组和只需要计算一次

```python
class Solution:

    def maxSubArray(self, nums: List[int]) -> int:
        n=len(nums)

        res=-inf

        @cache
        def dfs(i):
            if i == 0:
                return nums[0]
            return max(dfs(i-1)+nums[i],nums[i])

        for i in range(n):
            res=(max(dfs(i),res))
        return res
```

不过上述$O(n^2)$时间复杂度是我们加了for循环导致的，如果可以在递归的过程中就保留最大值，就不需要循环了，时间复杂度就可以缩小到$O(n)$
```python
class Solution:

    def maxSubArray(self, nums: List[int]) -> int:

        n=len(nums)
        res=-inf
        
        def dfs(i):
        
            nonlocal res

            if i==0:
                res=max(res,nums[0])
                return nums[0]

            cur_max=max(dfs(i-1)+nums[i],nums[i])
            
            res=max(res,cur_max)

            return cur_max

        dfs(n-1)

        return res
```

写成递推就是维护一个列表
1. 初始化列表的每个元素都是-inf
2. 然后循环遍历进行计算
```python
class Solution:

    def maxSubArray(self, nums: List[int]) -> int:

        n=len(nums)
        
        dp=[-inf]*n
        dp[0]=nums[0]

        res=dp[0]

        for i in range(1,n):

            dp[i]=max(dp[i-1]+nums[i],nums[i])
            res=max(res,dp[i])

        return res
```
时间复杂度和空间复杂度都是$O(n)$

优化空间复杂度有两种思路：原地修改和只动态维护一个前序最大值而不再维护一个列表，空间复杂度都可以优化到$O(1)$

原地修改：
```python
class Solution:

    def maxSubArray(self, nums: List[int]) -> int:

        n=len(nums)
        res=nums[0]

        for i in range(1,n):
            nums[i]=max(nums[i-1]+nums[i],nums[i])
            res=max(res,nums[i])

        return res
```

只动态维护一个前序最大值：
```python
class Solution:

    def maxSubArray(self, nums: List[int]) -> int:

        n=len(nums)

        res=nums[0]

        pre_max=nums[0]

        for i in range(1,n):
            cur_max=max(pre_max+nums[i],nums[i])
            res=max(res,cur_max)
            pre_max=cur_max

        return res
```
