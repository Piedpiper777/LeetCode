### 思路

首先，递归的思路

```python
class Solution:

    def fib(self, n: int) -> int:

        if n<2:
            return n

        return self.fib(n-1)+self.fib(n-2)
```

时间复杂度$O(2^n)$，第一层需要展开2个，第二层需要展开4个....
空间复杂度$O(n)$ 

想要优化时间复杂度，可以加上`@cache` ，这样时间复杂度就会变成$O(n)$，因为每个值都只计算了1次

空间复杂度仍然是$O(n)$ ，栈空间 + 哈希表缓存空间


如果想要继续优化空间，就必须放弃递归，不过我们可以手动原地维护这个递归逻辑


```python
class Solution:

    def fib(self, n: int) -> int:

        if n<2:
            return n

        a=0
        b=1

        for _ in range(2,n+1):
            a,b=b,a+b

        return b
```
