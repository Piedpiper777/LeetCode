
是否可以这样考虑：
双闭区间$[0,i]$的最长递增子序列有以下可能：
对于双闭区间$[0,i-1]$的最长递增子序列的最后一个元素$dp[i-1][-1]$
如果$nums[i]$大于$dp[i-1][-1]$，则将$nums[i]$加进去，否则还是延续？
好像不行，因为我们默认了必须要接上前面区间的最长递增序列，其实未必，比如$[4,5,1,2,3]$，不能延续需要重新开始，而且不能只看最长的，只要每一个都看一下，如果只看最长的，不行就重新开始等于放弃掉了前面的小元素

那应该怎么考虑呢？
可以循环遍历前面每一个元素
我们记$dp[i]$为以$nums[i]$结尾的最长子序列的长度，这样只需要比较$nums[i]$和$nums[j]$的大小关系，其中，$j∈[0,i)$，这样的话我们就需要在最后对以每一个元素结尾的最长子序列求最大值
```python
class Solution:

    def lengthOfLIS(self, nums: List[int]) -> int:

        n=len(nums)

        @cache
        def dfs(i):
            res=0
            for j in range(i):
                if nums[j]<nums[i]:
                    res=max(res,dfs(j))
            return res+1

        dp=0
        for i in range(n):
            dp=max(dp,dfs(i))

        return dp
```
复杂度分析：
- 时间复杂度：对于第$n$个元素计算$dfs(n)$，需要调用`dfs(0)`, `dfs(1)`, `dfs(2)`, `dfs(3)`...`dfs(n-1)`循环$i$次，而内部每一个都要循环，因此总次数等于$(n-1) + (n-2) + \dots + 2 + 1 + 0$，时间复杂度$O(n^2)$

- 空间复杂度：递归栈的最大深度为 **$n$**，占用空间 ${O}(n)$
如果不加`@cache`，时间复杂度${O}(2^n)$
假设用 $T(i)$ 表示计算 `dfs(i)` 所需要调用的函数总次数：
- $T(0) = 1$
- $T(1) = 1 + T(0) = 2$
- $T(2) = 1 + T(1) + T(0) = 1 + 2 + 1 = 4$
- $T(3) = 1 + T(2) + T(1) + T(0) = 1 + 4 + 2 + 1 = 8$
- ...
- **$T(n) = 2^n$

写成递推的形式
维护一个dp列表，记$dp[i]$为以$nums[i]$结尾的最长子序列的长度
```python
class Solution:

    def lengthOfLIS(self, nums: List[int]) -> int:

        n=len(nums)
        dp=[1]*n

        for i in range(n):
            for j in range(i):
                if nums[j]<nums[i]:
                    dp[i]=max(dp[i],dp[j]+1)

        return max(dp)
```

时间复杂度还是$O(n^2)$，如何优化呢？

创建一个列表$tails$，其中$tails[k]$表示长度为$k+1$的递增子序列的最小末尾元素，即$tail[0]$表示长度为$1$的递增子序列的最小末尾元素...

之所以要这样做，是为了让后面的元素可以接上，比如长度为$1$的递增子序列末尾元素可以是$1$也可以是$999$，那对于后面的元素接龙来讲，$1$更容易被接上，而$999$显然对后面接龙难度更大，因为我们需要关注的就是最小的那一种

用$res$记录长度，即如果当前$tails$的最后一个有效值是$tails[k]$则$res=k+1$

对于每一个$num$来讲，记此时最长的递增子序列长度为$res$，则我们需要在当前的$tails$中找到第一个大于等于$num$的并将其替换为$num$，如果没有，则在当前$tails$末尾加上$num$，然后$res+=1$

查找的过程是二分查找，二分查找的时间复杂度是$O(logn)$，由于每个num都需要进行二分查找，所以总体时间复杂度是$O(nlogn)$
空间复杂度是线性列表所占空间$O(n)$

```python
class Solution:

    def lengthOfLIS(self, nums: List[int]) -> int:
        n=len(nums)
        tails=[0]*n
        res=0

        for num in nums:
            ## tails的有效索引范围是闭区间[0,res-1]
            left=0
            right=res

            while left<right:
                mid=(left+right)//2

                if tails[mid]>=num:
                    right=mid
                else:
                    left=mid+1

            tails[left]=num

            if right==res:
                res+=1

        return res
```
