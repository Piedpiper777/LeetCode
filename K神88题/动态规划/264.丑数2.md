**丑数** 就是质因子只包含 `2`、`3` 和 `5` 的正整数。

每个丑数都可以由其他较小的丑数通过乘以 2 或 3 或 5 得到。


1 -> 2, 3, 5 ，丑数列表变为 [1, 2, 3, 5]
 2 -> 4, 6, 10 ，丑数列表变为 [1, 2, 3, 4, 6, 10]
 3 -> 6, 9, 15 
 
 但是会出现重复的，怎么处理？
 
我们维护一个结果列表，对于新出现的三个元素，首先需要去重，其次需要插入到列表，当然这两个步骤可以合并，但是需要每个元素遍历都需要3次二分查找，二分查找的时间复杂度是$O(logN)$，循环遍历是$O(mlogN)$

问题就在于，我们每次插入的元素数量实际上是不确定的，可能重复一个可能重复两个，想要得到第n个，如何控制循环呢？

想要控制循环就要每次只加入一个数，其他的放弃，但是这个放弃是会漏掉元素的，比如1得到2,3,5，如果只保留2，那么3和5就会被永远丢掉

如果不想丢掉这些元素，就还要留两个指针在这里继续后续计算，因为我们每次只保留一一个最小的，剩余的两个都需要保留，因此就需要三个指针来遍历。

或者简单来说就是，每个数都需要保留他的2,3,5倍的结果，但是一次只保留一个加入结果，对于保留的那一个就可以舍弃掉了，对于剩下的就还应该留在原地


我可以维护三个指针，分别表示下一个丑数是当前指针指向的丑数乘以 2 , 3 , 5

```python
class Solution:

    def nthUglyNumber(self, n: int) -> int:

        dp=[1]*n
        a=b=c=0

        for i in range(1,n):
            n1,n2,n3=dp[a]*2,dp[b]*3,dp[c]*5
            dp[i]=min(n1,n2,n3)

            if dp[i]==n1:
                a+=1
            if dp[i]==n2:
                b+=1
            if dp[i]==n3:
                c+=1

        return dp[-1]
```
- **时间复杂度**：$O(N)$（只需要遍历一次循环）
    
- **空间复杂度**：$O(N)$（用于存放前 $n$ 个丑数的数组）
