`'.'`是万能的
`'*'`是可以copy前面的，有两种用法：
- 匹配 **0 次**：直接删掉前面那个字符（相当于这一组规则作废）
- 匹配 **1 次、2 次、多次**：重复前面那个字符若干次

记原数组为$s$，长度为$m$，对照数字为$p$，由于`'*'`可以copy多个，所以$p$的长度是不定长的

记$s$的第$i$个字符是$s_i$，$p$的第$j$个字符是$p_j$，则将 $s$ 的前 $i$个字符组成的子字符串记为 $s[:i]$, 同理将 $p$ 的前 $j$ 个字符组成的子字符串记为$p[:j]$
问题转化为：判断$s[:i]$和$p[:j]$是否匹配，进而转为动态规划问题

记$dp[i][j]$表示$s[:i]$和$p[:j]$是否匹配，这里沿用python中的左闭右开，所以其实末尾元素分别是$s[i-1]$和$p[j-1]$

$p[j-1]$有三种情况：普通字符、`'.'`、`'*'`
- 如果$p[j-1]$是`'*'`，则以下条件任意一个成立即可：
	- 如果匹配前面$0$次，则需要$s[i-1]$和$p[j-3]$能匹配，即$dp[i][j-2]$是True
	- 如果$dp[i-1][j]$且$s[i-1]==p[j-2]$，则可以让$p[j-2]$多出现一次，因为$p[j-1]$本身就是`*`，多copy一次即可
	- 如果$dp[i-1][j]$且$p[j-2]=.$，则copy一下`'.'`
- 如果$p[j-1]$不是`'*'`，则以下条件任意一个成立即可：
	- 如果$dp[i-1][j-1]$且$s[i-1]==p[j-1]$
	- 如果$dp[i-1][j-1]$且$p[j-1]=.$

初始化$dp[0][0]=True$，因为是两个空字符串

```python
class Solution:

    def isMatch(self, s: str, p: str) -> bool:

        m=len(s)+1
        n=len(p)+1

        dp=[[False]*n for _ in range(m)]
        dp[0][0]=True

        for j in range(1,n):
            if p[j-1]=='*':
                dp[0][j]=dp[0][j-2]

        for i in range(1,m):
            for j in range(1,n):

                if p[j-1]=='*':
                    if dp[i][j-2] or (dp[i-1][j] and s[i-1]==p[j-2]) or (dp[i-1][j] and p[j-2]=='.'):
                        dp[i][j]=True

                else:
                    if (dp[i-1][j-1] and s[i-1]==p[j-1]) or (dp[i-1][j-1] and p[j-1]=='.'):
                        dp[i][j]=True

        return dp[-1][-1]
```
时间复杂度 $O(MN)$ ： 其中 $M,N$ 分别为 $s$ 和 $p$ 的长度，状态转移需遍历整个 $dp$ 矩阵。
空间复杂度 $O(MN)$ ： 状态矩阵 $dp$ 使用 $O(MN)$ 的额外空间。
