### 思路

动态规划问题，首先对于 `[i][j]` 位置，其最小路径和$res[i][j]$等于$min(res[i-1][j],res[i][j-1])+grid[i][j]$
也就是说，等于其左边和上边的最小路径和的最小值加上它自身

如果用递归的思路，边界条件是第一个点，如果超出边界就是无穷大，然后就可以递归了，不过如果直接递归，实际上类似斐波那契数列，一共有$m$行和$n$列的话，类似一个二叉树，树高$m+n$，则时间复杂度是$O(2^{m+n})$，空间复杂度是$O(m+n)$，我们可以用`@cache`来优化，这样每个节点计算一次，时间复杂度就是$O(m*n)$，空间复杂度也是$O(m*n)$
```python
class Solution:

    def minPathSum(self, grid: List[List[int]]) -> int:

        m=len(grid)
        n=len(grid[0])

        @cache
        def dfs(i,j):
            if i==j==0:
                return grid[0][0]

            if i<0 or j<0:
                return inf

            return min(dfs(i-1,j),dfs(i,j-1))+grid[i][j]

        return dfs(m-1,n-1)
```

转换成递推的思路：
1. 初始化一个dp二维列表
2. 对第一行和第一列进行处理
3. 对中间值进行处理
4. 返回`dp[m-1][n-1]` 
```python
class Solution:

    def minPathSum(self, grid: List[List[int]]) -> int:

        m=len(grid)
        n=len(grid[0])

        dp=[[inf]*n for _ in range(m)]
        dp[0][0]=grid[0][0]

        # 处理第一列
        for i in range(1,m):
            dp[i][0]=dp[i-1][0]+grid[i][0]

        # 处理第一行
        for j in range(1,n):
            dp[0][j]=dp[0][j-1]+grid[0][j]

        # 处理中间部分
        for i in range(1,m):
            for j in range(1,n):
                dp[i][j]=min(dp[i-1][j],dp[i][j-1])+grid[i][j]

        return dp[m-1][n-1]
```
- 时间复杂度$O(m*n)$
- 空间复杂度$O(m*n)$

如果想要优化空间，我们可以找一下规律，我们发现$dp[i][j]=min(dp[i-1][j],dp[i][j-1])+grid[i][j]$
 如果我们逐行遍历，第一行处理完成之后，在处理第二行时，比如对于$dp[1][1]$，我们需要用到$dp[0][1]$和$dp[1][0]$，但是$dp[0][1]$在处理完$dp[1][1]$之后将会彻底没用了会占用额外的空间，我们可以把$dp[1][1]$存储到$dp[0][1]$，这样就只需要一个长度为n的列表，空间复杂度就是$O(n)$，当然也可以先比较一下行列的大小，这样空间复杂度可以变成$\mathcal{O}(\min(m, n))$
 ```python
 class Solution:

    def minPathSum(self, grid: List[List[int]]) -> int:
        dp=[inf]*(len(grid[0])+1)

        dp[1]=0

        for row in grid:
            for j ,x in enumerate(row):
                dp[j+1]=min(dp[j+1],dp[j])+x

        return dp[-1]
 ```
