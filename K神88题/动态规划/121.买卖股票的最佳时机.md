### 思路

维护两个遍历，成本cost和利润res

成本cost从第一天开始维护
利润从第二天开始维护

先用第二天的价格计算利润

然后用第二天的价格更新成本

```python
class Solution:

    def maxProfit(self, prices: List[int]) -> int:

        cost=prices[0]
        res=float('-inf')

        for i in range(1,len(prices)):
            res=max(res,prices[i]-cost)
            cost=min(cost,prices[i])

        if res<0:
            return 0
        return res
```
