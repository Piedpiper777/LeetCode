### 思路

其实就是判断是否是有向无环图，如果存在环，则不成立

方法1：建立入度表

首先是遍历所有次序列表，建立邻接字典和入度字典，为所有的后续课程添加入度

然后建立一个队列，把所有入度为0的起始节点添加到队列中

遍历队列中的每一个起始节点，弹出，课程数目-1，让其下一个节点的入度-1，然后再将新的起始节点添加到队列中，如此循环往复，如果最终课程数为0说明无环，否则有环

```python
class Solution:

    def canFinish(self, numCourses: int, prerequisites: List[List[int]]) -> bool:

        # 遍历次序列表，建立入度字典和邻接字典
        indegrees=[0 for _ in range(numCourses)]
        adjaceny=[[] for _ in range(numCourses)]

        for p in prerequisites:
            indegrees[p[0]]+=1
            adjaceny[p[1]].append(p[0])

        # 建立队列，所有入度为0的起始节点入队
        dq=deque()
        for i in range(len(indegrees)):
            if indegrees[i]==0:
                dq.append(i)

        while dq:

            # 把起始节点弹出，总课程数-1
            pre=dq.popleft()
            numCourses-=1

            # 遍历弹出课程的所有下一个课程，其入度-1，如果入度为0，加入队列
            for cur in adjaceny[pre]:
                indegrees[cur]-=1
                if indegrees[cur]==0:
                    dq.append(cur)

        if not numCourses:

            return True

        return False
```


方法2：三色标记法

对每个节点定义三种颜色：0,1,2
0表示尚未访问
1表示正在访问，在当前的递归链中
2表示已经访问完毕

流程：
1.将前后次序转换成图
2.初始化颜色列表
3.写递归函数


```python
class Solution:

    def canFinish(self, numCourses: int, prerequisites: List[List[int]]) -> bool:

        # 1.建图
        graph=[[] for _ in range(numCourses)]
        for a,b in prerequisites:
            graph[b].append(a)

        # 2.建立颜色表，全部初始化为0
        colors=[0]*numCourses

        # 3.写递归函数
        def dfs(node):

            # 3.1 递归终止条件
            if colors[node]==1:
                return True # 说明找到环了
            if colors[node]==2:
                return False # 说明没找到环

            # 3.2递归主体
            # 先染色为1
            colors[node]=1
            # 递归
            for x in graph[node]:
                if dfs(x):
                    return True
            # 将node染色为2
            colors[node]=2
            return False

        for i in range(numCourses):
            if colors[i]==0:
                if dfs(i):
                    return False

        return True
```
