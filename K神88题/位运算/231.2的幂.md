我们可以把2的n次幂写成二进制观察一下规律
$2^0=1=0001$
$2^1=2=0010$
$2^2=4=0100$
$2^3=8=1000$
可以看到实际上每次都是1往左进1位
对于n-1呢
$2^0-1=0=0000$
$2^1-1=1=0001$
$2^2-1=3=0011$
$2^3-1=7=0111$

规律好像是$n&(n-1)=0$
但是要证明充分性
反证法：如果一个n不是2的幂，并且$n&(n-1)=0$，如果不是2的幂，那一定有多个1，n-1表示最右边的1变成0，该1右边的0变成1，则其左边一定存在1，这会与运算的结果就不会是0，所以如果$n&(n-1)=0$，则n一定是2的幂

```python
class Solution:
    def isPowerOfTwo(self, n: int) -> bool:
        if n>0 and n&(n-1)==0:
            return True
        return False
```
