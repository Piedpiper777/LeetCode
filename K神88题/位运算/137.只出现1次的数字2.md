与136题不同的是，其他元素都出现了3次，所以直接异或运算失效了

将所有数都写成二进制形式，记要找的数是x，对于某一个位置上
- 如果这个位置上的1的数目是3的倍数，则x在这一位是0
- 否则x在这一位是1，即这个位置上1的数目模3余1

```python
class Solution:

    def singleNumber(self, nums: List[int]) -> int:
        res=0
        for i in range(31):
            cnt1=0
            for num in nums:
                bit=(num>>i)&1
                cnt1+=bit
            res |= cnt1%3<<i

        cnt2=0
        for num in nums:
            bit=(num>>31)&1
            cnt2+=bit
        return res - (cnt2%3<<31)
```
- 时间复杂度：数组长度为 `n`；外层固定循环 **31 次**（0~30 数值位），外加单独 1 次符号位统计，总共常数次循环（32 次）；每一轮内部都要完整遍历一遍数组 `sum( x>>i&1 for x in nums )`，单次遍历 O (n)。总执行次数 = 32 × n 由于常数 32 在大 O 表示法中直接忽略，最终时间复杂度：**O(n)**
- 空间复杂度：O(1)
