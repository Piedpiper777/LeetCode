
考虑与运算
设二进制数字 $n$ ，则有：
- 若 $n&1=0$ ，则 $n$ 二进制 **最右一位** 为 $0$ 。
- 若 $n&1=1$ ，则 $n$ 二进制 **最右一位** 为 $1$ 。

这样我们可以逐位判断，判断一位之后将整个二进制序列右移一位$n>>=1$
```python
class Solution:

    def hammingWeight(self, n: int) -> int:
        res=0
        while n:
            res+=n&1
            n>>=1
        return res
```

- 时间复杂度：位移、与、加都是$O(1)$，时间复杂度主要在于循环遍历，其中我们输入的$n$是十进制数，因此循环次数是其二进制的有效位数，因此是$O(logn)$
- 空间复杂度：$O(1)$

还有一种思路可以稍微优化一下时间复杂度
$n-1$操作可以把二进制序列最右边的1变成0，把这个1右边的0变成1
$n&(n-1)$ 操作把该位置变成0
例如：
$n=$          $1 0 1 0 1 0 0 0$
$n-1=$   $1 0 1 0 0 1 1 1$
$n&(n-1)$=$10100000$
等于把最右边的1消掉了
这样我们就可以只考虑1，时间复杂度就是1的个数

```python
class Solution:

    def hammingWeight(self, n: int) -> int:
        res=0
        while n:
            res+=1
            n=n&(n-1)
        return res
```
