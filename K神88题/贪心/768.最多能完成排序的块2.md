
排序块 充分条件： 设此块中最大数字为 head , 若此块后面的所有数字都 >=head ，则此块为排序块。
 
排序块最短长度为 1，即单个元素可以独立看作一个排序块。

$head$一定是升序的
我们可以这样判断，对于一个元素$num$，如果$num>=head$，$num$可以开新块
如果$num<head$，则需要和前面块合并，并且需要找到合并的块，直到不再小于前面的$head$，所有路过的块都要合并成一个块

```python
class Solution:

    def maxChunksToSorted(self, arr: List[int]) -> int:

        #存储head
        stack=[]

        for num in arr:
            if stack and num<stack[-1]:
                head=stack.pop() #当前最大的head，暂存后续压入
                while stack and num<stack[-1]:
                    stack.pop()
                stack.append(head)

            else:
                stack.append(num)

        return len(stack)
```
