定义一种规则：
- 如果$a+b>b+a$，则$a>b$
- 如果$b+a>a+b$，则$b>a$

因此我们需要按照这个规则对列表进行排序，和对数字排序的逻辑其实类似，不过我们不能直接用sorted函数，需要自己写一个排序函数

之前有一题用过类似的排序思想，定位一个基准值，把小于等于的都放在左边，大于等于的都放在右边，然后递归左右两边
```python
class Solution:

    def largestNumber(self, nums: List[int]) -> str:

        # 写一个快速排序函数
        def quicksort(l,r):

            if l>=r:
                return

            i,j=l,r

            while i<j:
                while strs[j]+strs[l]>=strs[l]+strs[j] and i<j:
                    j-=1
                while strs[i]+strs[l]<=strs[l]+strs[i] and i<j:
                    i+=1
                strs[i],strs[j]=strs[j],strs[i]
            strs[i],strs[l]=strs[l],strs[i]

            quicksort(l,i-1)
            quicksort(i+1,r)
            
        strs=[str(num) for num in nums]
        quicksort(0,len(strs)-1)

        if strs[-1]=="0":
            return "0"
            
        return ''.join(strs[::-1])
```
时间复杂度分析：
- strs构建时的循环遍历$O(n)$
- 快速排序：每一层的工作量$O(n)$，一共需要递归$logn$，时间复杂度$O(nlogn)$，完全退化时$O(n^2)$
- 结果拼接$O(n)$
