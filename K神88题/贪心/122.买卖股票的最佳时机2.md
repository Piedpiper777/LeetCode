可以同一天多次买卖

对比121题，变化点在于最多只能交易 1 次：找历史最低点和历史最高点

这一题可以可以交易无限次

在“当前的选择不会破坏未来的最优可能性”时，全局最优=局部最优的和

贪心算法：
如果第二天价格高于当天，就买入卖出否则不动，即吃掉所有的上涨
```python
class Solution:

    def maxProfit(self, prices: List[int]) -> int:

        res=0
        n=len(prices)

        for i in range(n-1):
            if prices[i+1]>prices[i]:
                res+=prices[i+1]-prices[i]

        return res
```
- 时间复杂度：$O(n)$
- 空间复杂度：$O(1)$

当然也可以动态规划

记$dp[i]$表示第$i$天的最大收益，它有两种情况：$dp[i]=dp[i+1]+max(prices[i+1]-prices[i],0)$

```python
class Solution:

    def maxProfit(self, prices: List[int]) -> int:
        @cache
        def dfs(i):
            if i==0:
                return 0
            return dfs(i-1)+max(prices[i]-prices[i-1],0)

        return dfs(len(prices)-1)
```
- 对于单路线性递归（每个节点只有一个子节点），加不加 `@cache` 在时间复杂度（计算次数）上是没有数量级差异的，都是 $O(n)$

- 递归系统栈开销：由于递归深度最深为 $n$（从 $n-1$ 一路递归调用到 $0$），系统需要消耗 $O(n)$ 的栈空间来维护函数调用上下文

翻译成递推
```python
class Solution:

    def maxProfit(self, prices: List[int]) -> int:

        n=len(prices)
        dp=[0]*n

        for i in range(1,n):
            dp[i]=dp[i-1]+max(prices[i]-prices[i-1],0)

        return dp[n-1]
```

优化空间复杂度：

```python
class Solution:

    def maxProfit(self, prices: List[int]) -> int:

        n=len(prices)
        pre=0
        cur=0

        for i in range(1,n):

            cur=pre+max(prices[i]-prices[i-1],0)
            pre=cur

        return cur
```
