利用好该矩阵的特性
- 每行的元素从左到右升序排列。
- 每列的元素从上到下升序排列。

我们可以把这个矩阵逆时针旋转45度，这样就变成了一个类似二叉搜索树，即$left<root<right$

“根节点” 对应的是矩阵的 “左下角” 和 “右上角” 元素

以 `matrix` 中的 **左下角元素** 为标志数 `flag`，则有:
若 flag > target ，则 target 一定在 flag 所在 行的上方 ，即 flag 所在行可被消去。
若 flag < target ，则 target 一定在 flag 所在 列的右方 ，即 flag 所在列可被消去。

```python
class Solution:

    def searchMatrix(self, matrix: List[List[int]], target: int) -> bool:

        m=len(matrix)
        n=len(matrix[0])

        i=m-1
        j=0

        while i>=0 and j<n:
            if target<matrix[i][j]:
                i-=1
            elif target>matrix[i][j]:
                j+=1
            else:
                return True
                
        return False
```

- 时间复杂度：涉及循环，考虑循环次数M+N，$O(M+N)$
- 空间复杂度：$O(1)$
