双指针遍历
```python
class Solution:

    def maxArea(self, height: List[int]) -> int:

        n=len(height)
        left=0
        right=n-1
        res=0

        while left<right:
            if height[left]<height[right]:
                res=max(res,height[left]*(right-left))
                left+=1

            else:
                res=max(res,height[right]*(right-left))
                right-=1

        return res
```
- 时间复杂度：$O(N)$，双指针遍历一次底边宽度 N
- 空间复杂度：$O(1)$
