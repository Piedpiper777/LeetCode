
前序遍历的第一个节点就是根节点，第二个节点是root.left

如果可以在中序遍历中找到根节点的索引，那么其左边就是左子树，右边就是右子树

```python
class Solution:

    def buildTree(self, preorder: List[int], inorder: List[int]) -> Optional[TreeNode]:

        if not preorder:
            return None

        root=preorder[0]

        # 在中序遍历中找到root
        root_in_index=inorder.index(root)

        # 左子树大小
        left_size=root_in_index

        left=self.buildTree(preorder[1:1+left_size],inorder[0:root_in_index])
        right=self.buildTree(preorder[1+left_size:],inorder[1+left_size:])

        return TreeNode(root,left,right)
```

假设树共有 $N$ 个节点，在每次递归调用 `buildTree` 时，主要有三个操作消耗时间：

1. **查找根节点索引：`inorder.index(preorder[0])`**
    - Python 的 `list.index()` 是**线性查找**。如果在长度为 $K$ 的列表中查找元素，最坏需要 $\mathcal{O}(K)$ 的时间。
        
2. **列表切片（Array Slicing）：**
    - `preorder[1: 1 + left_size]` 和 `inorder[:left_size]` 等切片操作会**复制**元素，生成新的列表。
    - 切片长度为 $K$ 时，切片的时间复杂度也是 $\mathcal{O}(K)$。

3. **递归树的总节点数：**
    - 算法对每个节点都递归调用了一次 `buildTree`，总共递归 $N$ 次。

在最坏情况下（比如二叉树退化成一条链，呈单链表状）：

- 第 1 次递归处理长度为 $N$ 的列表，`index` 和切片需要消耗 $N$ 的时间；
    
- 第 2 次递归处理长度为 $N-1$ 的列表，消耗 $N-1$ 的时间；
    
- ...
    
- 第 $N$ 次递归消耗 $1$ 的时间。
    

总时间消耗为等差数列求和：

$$T(N) = N + (N-1) + (N-2) + \dots + 1 = \frac{N(N+1)}{2} = \mathcal{O}(N^2)$$

即使在最好情况（完全平衡二叉树）下，每层处理的节点切片和查找总和也是 $\mathcal{O}(N)$，共 $\log N$ 层，时间复杂度也需要 $\mathcal{O}(N \log N)$。因此总体最坏时间复杂度为 **$\mathcal{O}(N^2)$**。



空间复杂度由两部分组成：**递归系统栈深度** 和 **切片产生的额外内存空间**。

递归栈空间：
- 最坏情况（单链表树）：栈深度为 $\mathcal{O}(N)$。
- 平均/最好情况（平衡树）：栈深度为 $\mathcal{O}(\log N)$。

**切片产生的空间开销：**

- 因为每一层递归都在用切片 `[a:b]` **创建全新的 List 副本**。
- 最坏情况（单链表树）：每一层保存的列表长度分别为 $N, N-1, N-2 \dots$，占用的总空间也是 $\mathcal{O}(N^2)$。
- 平均情况（平衡树）：每一层所有递归函数持有的列表长度之和为 $\mathcal{O}(N)$，乘以递归树高度 $\mathcal{O}(\log N)$，总切片空间为 $\mathcal{O}(N \log N)$。



那怎么优化呢？
性能瓶颈在于：**① 用 `index()` 查找很慢**，**② 用切片复制数组浪费内存**


思路与上面类似，我们前序遍历中确定根节点，中序遍历找到根节点的位置然后确定左右子树的边界

一般情况下：
设根节点在中序遍历 `inorder` 中的索引 `i`

则
		根节点前序遍历索引	         中序遍历左边界	中序遍历右边界
左子树	          root + 1	                             left	                        i - 1
右子树	       root + i - left +  1	                 i + 1	                    right


```python
class Solution:

    def buildTree(self, preorder: List[int], inorder: List[int]) -> Optional[TreeNode]:

        # 建立中序遍历索引哈希字典
        index={val:idx for idx,val in enumerate(inorder)}

        # 对于一个子树的处理，我们需要：
        # 1.在前序遍历中找到这个点，然后再去中序遍历中映射拿到i
        # 2.在中序遍历中确定左右边界，其中，左子树的右边界是i-1，右子树的左边界是i+1
        # 所以只需要三个参数：前序遍历中根节点的位置root，中序遍历中左子树左边界和右子树右边界left和right

        def dfs(root,left,right):

            if left>right:
                return

            node=TreeNode(preorder[root])

            i=index[preorder[root]]

            node.left=dfs(root+1,left,i-1)
            node.right=dfs(root+i-left+1,i+1,right)

            return node

        return dfs(0,0,len(inorder)-1)
```
