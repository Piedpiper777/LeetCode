### 思路

首先可以这样写
```python
class Solution:

    def myPow(self, x: float, n: int) -> float:

        if n<0:
            return self.myPow(1/x,-n)

        if n==0:
            return 1

        return x*self.myPow(x,n-1)
```
但是时间复杂度是O(n)，非常慢

哪里可以优化呢？
**快速幂**

如果n是偶数，则$x^n=(x^{n/2})^2$ 
如果n是奇数，则$x^n=x^{n-1}*x$  

```python
class Solution:

    def myPow(self, x: float, n: int) -> float:

        if n<0:
            return self.myPow(1/x,-n)

        if n==0:
            return 1

        half = self.myPow(x,n//2)

        if n%2==0:
            return half*half
        else:
            return x*half*half
```


思路2

对于一个二进制数，比如十进制13可以写成1101，
$13=8+4+0+1=1*2^3+1*2^2+0*2^1+1*2^0$ 
$x^{13}=1*x^8+1*x^4+0*x^2+1*x^1$ 
前面的常数因子来自二进制的每一位
后面的指数值其实可以看成逐渐翻倍

```python
class Solution:

    def myPow(self, x: float, n: int) -> float:

        res=1

        if n<0:
            x=1/x
            n=-n

        while n:
            if n&1:
                res*=x
            x*=x
            n>>=1

        return res
```
