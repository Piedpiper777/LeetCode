### 思路

对根节点的left和right需要判断是否是相同子树，那需要判断left.left和right.right是否一样，left.right和right.left是否一样

如果全部不存在，则为边界条件

如果其中一个不存在或者值不同，则不一样

然后递归left.left和right.right 以及left.right和right.left
```python
class Solution:

    def isSymmetric(self, root: Optional[TreeNode]) -> bool:

        def function(l,r):

            if not l and not r:
                return True

            if not l or not r or l.val!=r.val:
                return False

            return function(l.left,r.right) and function(l.right,r.left)

        return function(root.left,root.right)
```
