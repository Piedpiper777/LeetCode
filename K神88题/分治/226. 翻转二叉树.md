### 思路

两种思路

一个是直接递归，对于根节点，只需要翻转左右两个节点即可
即root.left, root.right = root.right, root.left
但是只翻转这两个点没用，需要翻转左右两个树才行，所以需要递归
root.left=翻转（root.right)
root.right=翻转（root.left）

```python
class Solution:

    def invertTree(self, root: Optional[TreeNode]) -> Optional[TreeNode]:

        if not root:
            return

        tem=root.left
        root.left=self.invertTree(root.right)
        root.right=self.invertTree(tem)
        
        return root
```

另一种思路可以借助辅助栈，循环遍历一层层翻转

先在栈里加入root节点，然后当栈非空时循环，弹出一个，将其左右节点交换

```python
class Solution:

    def invertTree(self, root: Optional[TreeNode]) -> Optional[TreeNode]:

        if not root:
            return

        st=[root]

        while st:

            tem=st.pop()

            if tem.left:
                st.append(tem.left)

            if tem.right:
                st.append(tem.right)

            tem.left,tem.right=tem.right,tem.left

        return root
```
