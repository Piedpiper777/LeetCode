滑动窗口长度为k
可以维护一个计数器，右端进时判断一下，是否加1，左端出时判断一下是否减1

```python
class Solution:

    def maxVowels(self, s: str, k: int) -> int:

        vowels = {'a', 'e', 'i', 'o', 'u'}

        n = len(s)
        cnt = 0
        left = 0
        res = 0

        for right in range(n):
            if s[right] in vowels:
                cnt += 1

            # 窗口超长则左移

            if right - left + 1 > k:
                if s[left] in vowels:
                    cnt -= 1
                left += 1

            res = max(res, cnt)

        return res
```
- 时间复杂度：$O(N)$
- 空间复杂度：$O(1)$
