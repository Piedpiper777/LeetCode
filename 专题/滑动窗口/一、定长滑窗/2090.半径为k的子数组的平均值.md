一共有$i+k-(i-k)+1=2k+1$个元素
如果数组长度$n<2*k$，则全部是$-1$
左边需要空出$k$个元素，因此索引从$k$开始
右边需要空出$k$个元素，因此索引终点是$n-1-k$
即只有闭区间$[k,n-1-k]$有实际值

对于索引为$k$的元素
左半径和为$sum(nums[0:k])$
右半径和为$sum(nums[k+1:2*k+1]$

```python
class Solution:

    def getAverages(self, nums: List[int], k: int) -> List[int]:

        len_win=2*k+1
        n=len(nums)
        res=[-1]*n

        if n<len_win:
            return res

        win_sum=sum(nums[0:len_win])
        left=0
        right=len_win-1

        for i in range (k,n-k):
            res[i]=(win_sum)//len_win
            if right+1<n:
                right+=1
                win_sum=win_sum-nums[left]+nums[right]
                left+=1

        return res
```

不过其实用通用模版也可以写
```python
class Solution:

    def getAverages(self, nums: List[int], k: int) -> List[int]:

        n=len(nums)
        left=0
        res=[-1]*n
        win_sum=0
        win_len=2*k+1

        for right in range(n):
            win_sum+=nums[right]

            if right<2*k:
                continue

            res[right-k]=win_sum//win_len

            win_sum-=nums[left]
            left+=1

        return res
```
